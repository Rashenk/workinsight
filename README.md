# WorkInsight - SMM Management System

Полнофункциональная одностраничная система управления контентом и персоналом для SMM-агентства.

## 🎯 Возможности

### 📊 Основные разделы
- **Дашборд** — обзор проектов с графиками и статистикой
- **Проекты** — полная база проектов с фильтрацией
- **Аналитика** — отслеживание метрик (просмотры, подписки, взаимодействия)
- **Задачи** — управление задачами по проектам
- **Сотрудники** — база данных команды
- **Отчёты** — ежедневные отчёты о выполненной работе
- **Доступы** — хранение паролей проектов (только для админа)
- **Документация** — Регламент и Гайд для монтажёра

### 🔐 Система авторизации
- Двухролевая система (Администратор / Сотрудник)
- Система регистрации пользователей с email и телефоном
- Валидация данных при регистрации

### 📈 Графики и аналитика
- Chart.js для визуализации данных
- Интерактивные диаграммы
- Прогресс-бары с цветовой индикацией

### 💾 Персистентность
- Все данные сохраняются в localStorage
- Автоматическое восстановление данных при перезагрузке

## 🛠️ Технические требования

- Один HTML-файл (HTML + CSS + JS inline)
- Без фреймворков (React, Vue, Angular)
- CDN: Font Awesome 6, Chart.js 3.9.1
- Адаптивный дизайн (мобильные + ПК)

## 🚀 Запуск

1. Откройте файл `index.html` в браузере
2. Для входа используйте:
   - **Администратор**: пароль `admin2026`
   - **Сотрудник**: зарегистрируйтесь или используйте любое имя

## 📝 Начальные данные

При первом открытии приложение автоматически загружает:
- 14 проектов с разными статусами
- 5 записей аналитики
- 6 задач
- 7 сотрудников
- 4 доступа к проектам (только для админа)
