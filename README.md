# WorkInsight — SMM Management System

Система управления контентом и персоналом для SMM-агентства: проекты, аналитика,
задачи, отчёты, учёт рилсов и расчёт выплат.

## Архитектура

- **backend/** — Node.js + Express, база данных SQLite, JWT-аутентификация (`bcryptjs`).
- **frontend/** — одностраничное приложение на ванильном JavaScript, без фреймворков.
  Раздаётся статикой тем же Express-сервером.
- CDN: Font Awesome 6, Chart.js 3.9.1, SheetJS (XLSX).

## Возможности

### Основные разделы
- **Дашборд** — обзор проектов с графиками и статистикой
- **Проекты** — база проектов с фильтрацией
- **Аналитика** — метрики (просмотры, подписки, взаимодействия)
- **Задачи** — управление задачами по проектам
- **Сотрудники** — база данных команды
- **Отчёты** — ежедневные отчёты о выполненной работе
- **Рилс на сегодня** — счётчик рилсов и календарь публикаций
- **Финансы** — расчёт выплат сотрудникам
- **Доступы** — хранение паролей проектов (только для админа, шифрование AES-256)
- **Документация** — Регламент и Гайд для монтажёра

### Роли
- **Администратор** — полный доступ ко всем данным
- **Сотрудник** — доступ только к своим проектам, задачам, отчётам и аналитике

## Запуск

```bash
cd backend
npm install
npm start
```

Приложение будет доступно на `http://localhost:3000`.

При первом запуске база данных создаётся и наполняется начальными данными
автоматически.

### Учётные данные по умолчанию
- **Администратор** — `admin@workinsight.ru` / `admin123`
- **Сотрудники** — зарегистрируйтесь через форму или войдите под одним из
  предзаполненных сотрудников (пароль `password123`)

## Конфигурация

Настройки бэкенда — в `backend/.env` (см. `backend/.env.example`):

| Переменная       | Назначение                                       |
|------------------|--------------------------------------------------|
| `JWT_SECRET`     | Секрет для подписи JWT-токенов                    |
| `ENCRYPTION_KEY` | 32-символьный ключ AES-256 для паролей доступов   |
| `ADMIN_EMAIL`    | Email администратора при первичном наполнении     |
| `ADMIN_PASSWORD` | Пароль администратора при первичном наполнении    |
| `PORT`           | Порт сервера (по умолчанию 3000)                  |

Перед развёртыванием замените `JWT_SECRET` и `ENCRYPTION_KEY` на собственные
случайные значения.
